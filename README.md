# mcLauncher

Простой офлайн-лаунчер для **Minecraft 1.8.9** с графическим интерфейсом.  
Скачивает клиент, библиотеки и ресурсы, затем запускает игру без аккаунта Mojang.

## Возможности

- Графический интерфейс (тёмная тема)
- Консольный режим для запуска без GUI
- Автоматическая загрузка Minecraft 1.8.9 при первом запуске
- Настройка никнейма и объёма ОЗУ (1–8 ГБ)
- Поддержка Windows, macOS и Linux

## Требования

- **Python 3.10+**
- **JDK 8** (Java 8) — Minecraft 1.8.9 работает именно с этой версией

Проверить Java:

```bash
java -version
```

## Установка

1. Клонируйте репозиторий:

```bash
git clone <url-репозитория>
cd mcLauncher
```

2. Установите зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

### Графический режим (по умолчанию)

```bash
python launch.py
```

Или напрямую:

```bash
python gui.py
```

В окне лаунчера укажите никнейм, выберите объём памяти и нажмите **Играть**.

### Консольный режим

```bash
python launch.py --cli Player
```

С указанием объёма ОЗУ (в ГБ):

```bash
python launch.py --cli Player --memory 4
```

## Первый запуск

При первом запуске лаунчер скачает:

- клиент Minecraft 1.8.9;
- необходимые библиотеки;
- игровые ресурсы (ассеты).

Файлы сохраняются в стандартную папку `.minecraft`:

| ОС      | Путь                                              |
|---------|---------------------------------------------------|
| Windows | `%APPDATA%\.minecraft`                            |
| macOS   | `~/Library/Application Support/minecraft`         |
| Linux   | `~/.minecraft`                                    |

Повторные запуски используют уже скачанные файлы и стартуют быстрее.
